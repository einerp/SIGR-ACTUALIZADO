Despliegue Supabase & Vercel

SIGR está listo para conectarse a tu base de datos PostgreSQL y almacenamiento de imágenes en Supabase, y desplegarse en Vercel.

  1. Crea un proyecto en Supabase y ejecuta supabase/schema.sql en el SQL Editor.
  2. Opcionalmente ejecuta supabase/seed.sql para cargar platos y clientes de prueba.
  3. Configura las variables SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY y SUPABASE_STORAGE_BUCKET en .env o en Vercel Project Settings.
  4. Sube el repositorio a GitHub e impórtalo en Vercel (ya incluye vercel.json y api/index.js).
